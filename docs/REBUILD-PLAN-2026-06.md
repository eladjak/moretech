## 0. מה היה שבור — ולמה התכנית הזו טובה יותר

הפרויקט סבל מ**שתי נשמות מתנגשות**:

1. **V1 (האמיתי)** — ספק של קורסים, סדנאות, קייטנות והרצאות טכנולוגיה+AI לבתי ספר ולרשתות. זה מה שאלעד באמת יודע, רוצה ויכול לספק *מחר*. יש לזה קטלוג חוויות אמיתי ומחירון אמיתי (`business-docs/`), לוגואים, ותמונות סדנה.
2. **V2 (הסטייה)** — pivot ל-SaaS "MagicSchool הישראלי" עם פלטפורמת כלי-AI למורים. תכנית מצוינת על הנייר, אבל דרשה גיוס, beta, וצוות — והרחיקה את אלעד מהיתרון האמיתי שלו (ההוראה, הנוכחות, החום).

הרטרוספקטיב של 19.4 אבחן את זה במדויק: *"הפער לא היה במודל העסקי — אלא בעומס המכירה/תפעול הידני."*

**הסינתזה (התכנית הזו):** אתר B2B אחד, ממוקד-המרה, ש**מוביל ב-V1** (קטלוג פעילויות + תכניות הכשרת מורים שאפשר להזמין היום) ו**משתמש ב-V2 כהוכחת-יכולת** — דמו חי ועובד של מחולל-השיעורים ב-AI, ישירות באתר. בלי pivot ל-SaaS, בלי beta-gating, בלי הבטחות ריקות. הדמו הוא ה"וואו" שמוכיח שאלעד חי ונושם AI — והקטלוג הוא מה שבית ספר באמת קונה.

מדד: בית ספר/רשת נכנס לאתר → מבין את הכאב (מחסור מורים, "שנת AI") → רואה קטלוג פעילויות אמיתי שאפשר לסנן ולבחור → מנסה בעצמו את מחולל-השיעורים → קובע שיחה. הכל בעברית RTL, מהיר, נגיש, ו-GEO 100.

## 1. החלטת ארכיטקטורה — איחוד לאפליקציה אחת

**היום:** שני אפליקציות Next.js נפרדות (`website/` שיווקי + `platform/` עם כלי AI), כש-`platform` הוא git-repo מקונן ללא `.gitmodules` (מבלבל, "m" ב-git status).

**ההחלטה:** **אפליקציית Next.js 16 אחת בשורש `app/`** (App Router, React 19, TS, Tailwind 4, Framer Motion, bun). היתרונות:
- דף שיווקי ודמו ה-AI חיים יחד → ניווט אחד, מותג אחד, deploy אחד.
- ה-API route של מחולל-השיעורים יושב באותו פרויקט → אין CORS, אין הפרדה.
- פחות תחזוקה, build מהיר יותר, deploy פשוט.
- מסירים את ה-git-repo המקונן.

`website/` ו-`platform/` הישנים נשמרים כ-reference היסטורי (לא נמחקים, לא מתעדכנים) — ה-build החדש ב-`app/` בשורש.

**Stack סופי:**
| שכבה | בחירה | סיבה |
|------|-------|------|
| Framework | Next.js 16 App Router | RSC, מהיר, SEO, API routes לדמו |
| שפה/UI | TypeScript · Tailwind 4 · Framer Motion | סטנדרט, אנימציות transform/opacity |
| נגישות | Radix primitives (Select/Dialog) | מקלדת+focus מובנים |
| AI | Vercel AI SDK → Gemini (חינם) / Claude אם יש מפתח | free-degradation |
| Hosting | Vercel (`*.vercel.app`) | quota התאפס; preview deploys |
| תמונות | nano-banana-poster (Gemini, חינם) | hero + אייקוני נושא, ללא placeholders |

## 2. החלטת מותג (להחלטת אלעד)

הריפו נקרא "moretech" אבל החומרים מובילים ב-**EduTech** כמותג-גג, עם תתי-מותגים:
- **EduTech** = מותג-גג (לוגו: נורת-מעגל מתוך ספר פתוח, כחול+ירוק).
- **MoreTech** = תת-מותג הכשרת מורים B2B.
- **HiTechKids** = תת-מותג סדנאות/קייטנות ילדים (לוגו: רובוט כחול).
- (עתיד: EduTech Pro / Edu / Camp — כבר מופיעים במחירון האמיתי כקטגוריות).

**המלצה:** להוביל ב-**EduTech** כמותג-גג (הכי חזק, הכי רחב, תואם את הקטלוג המלא), ולמצב את MoreTech/HiTechKids כקווי-מוצר תחתיו. זה תואם את `STRATEGIC-PLAN-2026.md` ואת מבנה המחירון האמיתי.

**🟡 החלטה נדרשת מאלעד:** האם המותג-הראשי באתר = "EduTech" (מומלץ) או "MoreTech"? + דומיין (סעיף 8).

## 3. מבנה האתר (sections)

1. **Hero** — כותרת מוטיבית + תת-כותרת B2B + 2 CTA (קבעו שיחה / נסו את הדמו) + רקע תמונה (Gemini) + 3 סטטיסטיקות אמיתיות מ-RESEARCH.md.
2. **הבעיה** — מחסור מורי הטכנולוגיה (נתונים אמיתיים: ירידה 22% במורים חדשים, 216 משרות פנויות, ירידה 40% בסטודנטים למדמ"ח, "שנת AI", תקציב 1.485 מיליארד ₪) — כל נתון עם מקור.
3. **הפתרון** — מה EduTech מספק: הרצאות, סדנאות, קורסים, קייטנות, הפנינגים, פיתוח מקצועי למורים — 6 קטגוריות מהקטלוג האמיתי.
4. **קטלוג פעילויות (אינטראקטיבי)** — *מרכז האתר #2*. Finder עם סינון לפי גיל + נושא + פורמט, כרטיסים עם אייקון/נושא, שם, גיל, פורמט, תוצרי-למידה, ו-CTA "בקשו פעילות זו".
5. **דמו חי: מחולל שיעורי AI** — *מרכז האתר #1*. המבקר מזין מקצוע+כיתה+נושא → מקבל מערך שיעור. Free-degradation: גנרטור-תבנית איכותי תמיד עובד; משודרג ל-AI אמיתי אם יש מפתח.
6. **איך זה עובד** — 4 צעדים מהפנייה ועד הפעילות בבית הספר.
7. **למי זה מתאים** — רשתות חינוך / מנהלי בתי ספר / רכזי תקשוב / רשויות.
8. **אמון/חברתי** — עובדות אמיתיות בלבד (תמונות סדנה אמיתיות, ניסיון, מותגים) + כל מספר-דוגמה מסומן "להמחשה".
9. **חבילות ותמחור** — מהמחירון האמיתי (`business-docs`): טווחי מחיר אמיתיים לפי קטגוריה + הנחות/תוספות. ללא בדיית מספרים.
10. **CTA סופי + טופס יצירת קשר** (B2B: קבעו שיחה).
11. **FAQ** — ≥6 שאלות (schema FAQPage).
12. **Footer** — תתי-מותגים, ניווט, יצירת קשר, NAP.

## 4. קטלוג פעילויות לבתי ספר (התוספת של אלעד)

**הבסיס אמיתי:** המחירון של EduTech (`business-docs/טבלת חוויות ותמחור.docx`) כבר מכיל **~32 חוויות אמיתיות** ב-8 קטגוריות (הרצאות, סדנאות AI, סדנאות Kids, Pro, Edu למורים, קורסים/סמינרים, קייטנות, הפנינגים, פיתוח מקצועי). אנו בונים על אלה ומוסיפים פעילויות **מקוריות** חדשות לכיסוי תמטי מלא — סה"כ **18 פעילויות מובחרות** לקטלוג האתר, ממופות לפי:
- **שם עברי קליט**
- **קהל יעד** (תלמידים / מורים / כלל בית-ספרי / ערב הורים)
- **גיל/שכבה** (גן–ד' / ה'–ח' / ז'–יב')
- **פורמט/משך** (מפגש בודד / תכנית רב-שבועית / יום שלם)
- **תוצרי למידה**
- **נושא** (AI / תכנות / רובוטיקה / יצירה / אתיקה ואזרחות דיגיטלית / יזמות)
- **מה מיוחד בה**

הרשימה המלאה (18) מפורטת ב-`app/data/activities.ts`. תמהיל הנושאים: AI literacy, prompt-engineering, build-a-chatbot, AI ethics & critical thinking, hands-on no-code ML, רובוטיקה, creative-AI (תמונה/מוזיקה/סיפור), חשיפת קריירה, האקתון/דאטהתון, co-learning מורה+תלמיד, אזרחות דיגיטלית ובטיחות, עיצוב משחקים, חשיבה חישובית unplugged, ועוד.

**איך זה חי באתר (web-paradigm-shift):** לא רשימה סטטית — **Activities Finder אינטראקטיבי**: chips לסינון לפי גיל+נושא+פורמט, ספירה חיה, כרטיסים עם אייקון-נושא (אילוסטרציה Gemini עקבית פר-נושא), ו-CTA "בקשו פעילות זו" שממלא מראש את טופס יצירת הקשר. בית ספר *בוחר* — לא רק קורא.

מחירים בקטלוג מסומנים "מחיר בסיס להמחשה" כשהם נגזרים מהמחירון; טווחי המחיר האמיתיים מופיעים בסעיף התמחור.

## 5. הדמו החי — מחולל שיעורי AI (free-degradation)

הלב של web-paradigm-shift: **כפתור חי, לא מת.**
- טופס: מקצוע (select) · שכבת גיל (select) · נושא (text) · משך · הערות.
- **Tier 0 (תמיד עובד, ללא מפתח):** גנרטור-תבנית דטרמיניסטי שמרכיב מערך-שיעור פדגוגי מלא בעברית (פתיחה/גוף/סיכום, מטרות, דיפרנציאציה, הערכה) מהקלט — איכותי מספיק כדי להרשים, מסומן "נוצר מתבנית — חברו מפתח AI לתוצר מותאם-עומק".
- **Tier 1 (אם `GEMINI_API_KEY`/`ANTHROPIC_API_KEY` קיים):** streaming אמיתי דרך Vercel AI SDK עם system-prompt פדגוגי ישראלי.
- העתקה-ללוח, מצב טעינה, מצב שגיאה → fallback ל-Tier 0. אין מסך מת.

זהו דפוס Pollr/ninja: דמו שלם בלי תלות במפתח בתשלום, משודרג כשיש.

## 6. עיצוב, נגישות, ביצועים

- **מותג:** כחול EduTech (#1B4D8E) + ירוק (#2E9E3F) + ליים-accent (#A4D233) מהלוגו. Heebo/Assistant. RTL.
- **Hebrew RTL gotchas:** חצים `scaleX(-1)`, `tabular-nums` למספרים, line-height ≥1.5, ללא italic-serif, ₪ עם פסיק.
- **תנועה:** transform+opacity בלבד, ≤200ms feedback, `prefers-reduced-motion`.
- **a11y:** Radix ל-Select/Dialog, `aria-label` לכפתורי-אייקון, ניווט מקלדת, focus נראה, alt לכל תמונה.
- **ביצועים:** `next/image`, lazy-load מתחת לקיפול, פונט עם `display:swap`.

## 7. GEO/AEO + SEO (יעד 100)

- JSON-LD כ-`<script>` רגיל ב-layout (לא next/script): **EducationalOrganization + Service + FAQPage + WebSite + BreadcrumbList**.
- h1 יחיד, meta description 120–160, OG+Twitter, favicon, canonical, `lang=he dir=rtl`.
- `robots.txt` (Allow לכל בוטי-AI), `sitemap.xml`, `llms.txt`.
- alt לכל תמונה, תגיות סמנטיות (main/section/article/nav/header/footer), היררכיית כותרות מאוזנת, ≥5 קישורים חיצוניים אמיתיים בתוכן (מקורות RESEARCH).
- scan עם geo-scan (עצמי, ללא quota) אחרי deploy.
